# 面试准备实操指南：从准备到收尾

> 来源：ai-job-search 项目方法论。核心思想：面试是可以准备的，不是靠临场发挥。这里编码的是面试前、中、后的全套实操经验。STAR 评分标准见 `behavioral-rubric.md`，回答层次诊断见 `interview-coaching.md`。

---

## 面试准备三步法

### 第一步：公司研究

每次面试前必做：

- [ ] 官网：mission、values、最近新闻
- [ ] 产品：核心产品线、技术栈（从 JD 和技术博客推断）
- [ ] 团队：LinkedIn 搜团队规模、最近入职的人、manager 背景
- [ ] 面试官：如果知道名字，查技术背景和关注方向
- [ ] 评价：Glassdoor/脉脉/看准网看面试体验和公司口碑

### 第二步：故事准备

准备 3-5 个核心 STAR 故事，每个覆盖不同能力维度（详见 `behavioral-rubric.md` 的必备故事表）。每个故事准备两个版本：

- **2 分钟版**：S/T/A/R 各一句话，面试官不追问时用
- **4 分钟版**：深入细节，面试官追问时展开

### 第三步：问题准备

准备以下三类问题的回答 + 你要反问的问题。

## 常见棘手问题与应对

### "请介绍一下你自己"

**不要**：复述简历。**要**：2-3 分钟精练版——

```
"我做了 X 年 Y 方向，核心能力是 A/B/C。最近在做 Z，
取得了 XX 成果。看到贵司这个岗位在做 W，和我的经验很匹配。"
```

**公式：** 过去（做了什么）+ 现在（核心能力）+ 未来（为什么是这个岗位）

### "你为什么离开上一家公司？"

**原则：** 诚实、前向、不负面评价前雇主。

```
"我在上一家公司做了 X，学到了 Y。但我在 Z 方向想深入发展，
而前公司在这方面空间有限。贵司在 Z 方向的工作正是我想要的。"
```

### "你最大的弱点是什么？"

**原则：** 说真实的弱点 + 具体的改进措施。不说"我太追求完美"这种伪装。

```
"我之前在 X 方面比较弱。后来我通过 Y 方法来改进，
现在可以做到 Z。还在持续提升中。"
```

### "你未来 5 年的规划是什么？"

**原则：** 展示与岗位成长路径对齐的野心。

```
"短期内我希望在 X 方向深耕，成为团队中能独立解决 Y 类问题的人。
中期来看，我希望在 Z 领域建立更深的专业度，能带领小团队攻克这类问题。"
```

### "你为什么选择我们公司？"

**原则：** 必须提到具体信息——产品、技术、团队、市场地位。绝对不通用。

```
"我一直关注贵司在 X 领域的工作。你们的 Y 产品/技术在 Z 方面做了 A，
这个方向和我之前做 B 的经验高度相关，而且我想在 C 方面进一步深入。"
```

### "你之前没有 X 经验"

**原则：** 承认缺口 + 架桥到相邻经验 + 展示学习意愿。

```
"确实，我目前的经验主要在 Y 领域。但这两者的核心能力是相通的——
比如 Z 和 W。我可以在 2-3 周内快速上手 X 的基础，入职后第一周就能开始贡献。"
```

### "你期望的薪资是多少？"

**原则：** 不先报价。详见 `salary-negotiation.md`。

```
"我希望薪资能反映我的能力和贡献，您方便分享一下这个级别的薪资范围吗？"
```

## 反问面试官的问题库

**反问环节是面试的一部分，不是可有可无。** 好的问题展示你的思考深度和对岗位的认真程度。

### 关于岗位

- "这个岗位日常的一天大概是什么样的？"
- "入职前 6 个月做到什么算成功？"
- "团队目前最大的技术挑战是什么？"
- "这个岗位为什么是空缺的——是新增还是替换？"

### 关于团队

- "团队大概多少人？怎么分工？"
- "从需求到上线，你们的开发流程是什么样的？"
- "新人的 onboarding 流程是什么样的？"
- "团队里最资深的人一般做什么，最 junior 的人做什么？"

### 关于技术与成长

- "你们目前在用什么技术栈？有没有计划引入新技术？"
- "这个岗位以后有没有往架构/管理方向发展的空间？"
- "团队怎么保持技术更新？有没有内部技术分享或学习预算？"
- "代码审查、测试、文档的要求是怎样的？"

### 关于文化（用这些问题避免入职后失望）

- "你怎么描述团队文化？"
- "公司对技术债务的态度是什么？"
- "远程/混合办公的灵活性怎么样？"
- "加班情况怎么样？是有固定节奏还是偶尔？"
- "你觉得什么样的人在这个团队里最成功？"
- "这个团队和你待过的其他团队最大的不同是什么？"

## 模拟面试角色扮演指南

当用户要求模拟面试时：

### 流程

1. **确认目标公司和岗位**（如果有 JD 最好）
2. **热身题**：从简单的自我介绍开始（"介绍一下你自己"）
3. **技术题**：2-3 道与 JD 和用户背景相关的技术问题
4. **行为题**：1-2 道基于 JD 中能力要求的行为问题
5. **收尾题**：1 道稍微刁钻的问题（压力测试）
6. **每题后给简短反馈**：哪里做得好，哪里可以更锋利
7. **建议**：这道题用哪个 STAR 故事最合适

### 出题原则

- 题目难度递进，不要一开始就上最难的
- 行为题使用 JD 中的具体能力要求
- 追问时从"具体怎么做"、"为什么选这个方案"、"有没有其他选择"三个角度深入
- 至少一道题是用户可能没准备过的（测试临场反应）

### 反馈原则

- 先说亮点（"这道题你 X 做得很好"），再说改进
- 改进建议要具体可执行（"下次可以加一句 Y"）
- 引用 `interview-coaching.md` 的层次模型（"你目前停留在 L2 对比层，可以升级到 L3 决策层"）
- 引用 `behavioral-rubric.md` 的评分标准（"STAR 清晰度 3 分，R 缺失"）

## 电话/视频面试技巧

- 面前准备好 STAR 故事（打印或第二屏幕）
- 准备一杯水在旁边
- 说话时微笑（会改变语气）
- 问题不清晰时主动要求澄清
- 允许自己花 5 秒思考再回答——这是正常表现
- 结束时问："还有其他想了解我的背景的吗？"

## 面试后跟进

### 感谢信

收到任何更新（面试邀请、拒绝、状态更新）时，发送简短感谢：

> "感谢您的 [时间/回复/邀请]。很期待 [下一步/继续交流/未来的机会]。"

**2-3 句话，不要长篇大论。**

### 未回复时跟进

- 如果雇主给了时间线，尊重时间线等待
- 如果没有时间线且超过 2 周，可以简短询问状态
- 最多跟进 2 次，不要骚扰
- 如果有了新的、相关的信息（如新项目上线），可以分享

## Agent 方向面试特别准备

### 高频技术问题领域

| 领域 | 准备重点 |
|------|---------|
| Agent 架构 | ReAct vs Plan-Execute 的选择标准、多 Agent 协作模式 |
| Tool/Function Calling | Schema 设计、错误处理、工具调用循环控制 |
| RAG 系统 | Chunk 策略、检索 pipeline、Rerank、HyDE |
| Prompt Engineering | Chain-of-Thought、结构化输出、Few-shot vs Zero-shot |
| 生产化 | Token 成本控制、延迟优化、可观测性、幻觉缓解 |
| 模型选型 | GPT vs Claude vs 开源模型的适用场景 |

### 高频行为问题领域

- "说一个你从零搭建系统的经历"（展示系统思维和主动性）
- "LLM 输出不稳定时你怎么处理？"（展示工程容错思维）
- "Agent 和传统软件最大的区别是什么？你怎么应对？"（展示领域理解深度）
- "你怎么跟上 AI 领域的变化速度？"（展示学习策略）

### 准备一份 Agent 项目 portfolio

每个 Agent 项目都用以下结构准备：

```
项目：XXX Agent 系统
- 解决的问题：XXX
- 架构选择：为什么选 ReAct 而非 Plan-Execute
- 技术栈：LLM (GPT-4) + 工具层 (12 个 Function) + 向量库 (Milvus)
- 核心指标：成功率 94%、平均延迟 3.2s、日均调用 5000 次
- 最大挑战：XXX（怎么解决的）
- 如果重来：XXX（展示反思深度）
```
